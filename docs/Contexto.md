DocSender é pensado para ser uma solução para sistemas antigos que não possuem integração com o whatsapp por exemplo sistemas erp
a ideia aqui é fazer com que documentos gerados pelo erp sejam e que precisam ser enviasdos a clientes pelo whatsapp sejam enviados de forma autonoma

passo 1
    definir como esse sistema funcionará, seja um serviço que le uma pasta, seja um sistema por demanda que precisa de interação para o envio etc discutiremos isso
passo 2
    o sistema deve enviar os arquivos via evolution api, por isso deve seguir alguns cuidados para não ter o numero do usuario banido
